Smart Quota & Reset Alerts

Opt-in native OS notifications when a quota crosses below 20% / 15% / 10% / 5% — and again when your 5h window resets back to 100%.

Multi-Provider in One HUD

One-click GitHub Releases updates on macOS, Windows, and Linux with fail-closed SHA256 verification against SHA256SUMS.txt.

Universal binary for Apple Silicon & Intel (macOS 13+). Includes native SHA256-verified auto-updates.

Transparent by design

Open-source MIT code you can audit in minutes — zero hidden network calls.

Local Loopback Default

Antigravity quotas are fetched directly from your local Language Server on 127.0.0.1 with zero API keys.

Strictly Opt-In Providers

Claude Code and Codex CLI stay disabled until you toggle them on in Settings. Credentials never leave your machine.

Fail-Closed Verification

Every auto-update download is hashed locally with SHA256 and aborted immediately if it doesn't match SHA256SUMS.txt.
